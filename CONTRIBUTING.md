# Contributing

The project is at an early stage. Before larger changes:

- Read [DESIGN.md](DESIGN.md) for the visual rules.
- Keep view models free of Avalonia window types; go through the interfaces in `NudgeJudge/Services/` instead.
- New matching or validation logic in `NudgeJudge.Core` should come with tests.

See [Getting started](docs/getting-started.md) to build and run the tests, and [Architecture](docs/architecture.md) for how the code is laid out.
